# Русскоязычный контракт Remote AI

Remote AI — русскоязычный продукт. Этот документ фиксирует границу между пользовательским текстом, который обязан быть на русском языке, и техническими идентификаторами, которые переводить нельзя.

## Что всегда должно быть на русском

- подписи, кнопки, подсказки и тексты Настроек;
- контекстное меню маскота;
- accessibility labels/hints и VoiceOver-описания;
- уведомления macOS;
- ошибки конфигурации, SSH, Mutagen и runtime, сформированные самим Remote AI;
- основной текст состояния приложения;
- заголовки локального Git-обзора в Warp;
- README, CHANGELOG, SECURITY, CONTRIBUTING и проектная документация;
- описания локальных агентов и правила репозитория;
- GitHub issue/PR templates;
- названия шагов CI/CD и сообщения собственных shell-скриптов;
- release notes и подписи на релизных снимках интерфейса.

## Что не переводится

- имена библиотек и продуктов: OpenSSH, Mutagen, tmux, Claude Code, Warp, Terminal, Swift, SwiftUI, AppKit;
- имена файлов, путей, классов, функций и переменных;
- shell-команды, CLI flags и environment variables;
- protocol/state tokens, которые являются машинным интерфейсом: `thinking`, `waiting`, `offline`, `error`, `__RA_*`;
- Git refs, branch/tag naming и bundle identifiers;
- сырой вывод внешнего инструмента, если Remote AI не контролирует его локализацию.

## Главное UX-правило

Сырой англоязычный вывод внешнего инструмента нельзя использовать как основной пользовательский статус. Сначала Remote AI должен интерпретировать состояние и показать короткую русскую формулировку. Необработанный вывод допускается только как дополнительная техническая диагностика.

Пример:

- плохо: `Status: Staging files on beta`;
- хорошо: `Mutagen синхронизирует изменения.`;
- при необходимости ниже можно показать исходную diagnostic строку.

## Единый словарь состояний

| Внутренний token | Пользовательское название |
| --- | --- |
| `offline` | Не в сети |
| `connecting` | Подключение |
| `syncing` | Синхронизация |
| `thinking` | Claude Code работает |
| `waiting` | Ожидание ввода |
| `error` | Ошибка |

Действия:

- `Choose Project` → **Выбрать проект…**
- `Start / Reconnect` → **Запустить / переподключить**
- `Open Review in Warp` → **Открыть обзор в Warp**
- `Attach in Terminal` → **Подключиться в Terminal**
- `Stop` → **Остановить**
- `Settings` → **Настройки…**
- `Quit` → **Завершить Remote AI**
- `Test Setup` → **Проверить настройку**

## Проверка перед merge

1. Просмотреть light/dark snapshots Settings и лист состояний маскота.
2. Проверить VoiceOver/accessibility строки.
3. Выполнить поиск старых пользовательских фраз на английском.
4. Убедиться, что новый пользовательский текст документирован в `docs/GLOSSARY.md`, если вводит новый термин.
5. Не переводить машинные tokens или команды ради визуальной «чистоты».
6. `swift test --parallel`, release build и snapshot gate должны пройти.

## Правило для агентов

Любой агент, добавляющий пользовательскую строку на английском, обязан либо перевести её на русский, либо явно доказать, что это технический identifier/API/сырой внешний вывод. Локализация является частью acceptance criteria, а не отдельной постобработкой.
