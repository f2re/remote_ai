# Чек-лист ручной проверки отказов

Выполнять после unit tests на временном рабочем пространстве.

1. **SSH недоступен.** Остановить/заблокировать сервер. Маскот должен перейти в «Не в сети» без error loop; удалённая tmux-сессия не должна измениться.
2. **Reconnect.** Вернуть SSH. Существующие Mutagen/tmux names должны переиспользоваться без дублей workspace/session.
3. **Mutagen отсутствует.** Временно убрать Mutagen из PATH. Запуск должен показать понятную русскую dependency error и не удалять remote data.
4. **tmux отсутствует.** Использовать host без tmux. Запуск должен завершиться до создания Claude-сессии.
5. **Claude отсутствует.** Использовать host без `claude`. Remote AI показывает понятную ошибку и не пытается устанавливать/подменять бинарник.
6. **Sync conflict.** Изменить один tracked file по-разному с двух сторон при отключённой связи. После reconnect маскот показывает «Ошибка»; Stop не должен убить/pause до успешного flush.
7. **Смена host key.** Имитировать изменившийся SSH host key. Подключение обязано завершиться ошибкой; `StrictHostKeyChecking=no` никогда не используется.
8. **Sleep/network loss во время работы.** Отключить Mac при активном Claude. Remote tmux продолжает работать; после reconnect файлы догоняются, состояние возвращается к синхронизации/работе/ожиданию.
9. **Terminal attach.** Custom SSH port и identity присутствуют в generated attach command.
10. **Notification.** Переход «Claude Code работает» → «Ожидание ввода» создаёт одно уведомление, а не повторяется на каждом poll.
11. **Локализация.** Все собственные ошибки, notifications, Settings и action labels остаются русскими; внешний сырой вывод не используется как основной status.
