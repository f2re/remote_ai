# Remote AI v0.2.0

Релиз функционального укрепления Remote AI.

Главное:

- встроенная неразрушающая диагностика проекта, SSH, Mutagen, tmux и Claude Code;
- ограниченные по времени SSH-подключения с понятными ошибками;
- восстановление существующей tmux/Claude-сессии после перезапуска приложения;
- route-scoped Mutagen sessions и безопасная миграция старых маршрутов;
- Universal 2 (`arm64 + x86_64`);
- детерминированные light/dark snapshots;
- проверяемый CI/CD с tag guard, checksums и GitHub Release assets.

Environment-dependent E2E на реальном пользовательском сервере отслеживается отдельно, поскольку GitHub CI не имеет доступа к пользовательскому SSH-host и авторизованному Claude Code.
