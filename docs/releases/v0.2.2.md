# Remote AI 0.2.2

Выпуск закрепляет новый канонический пиксельный маскот Remote AI во всём продукте.

## Что изменилось

- шесть новых PNG-состояний облака используются непосредственно приложением;
- прежний процедурный «белый» силуэт удалён из runtime;
- состояние облака теперь визуально различается не только цветом: сон, подключение, синхронизация, работа, ожидание и ошибка имеют собственный арт;
- иконка приложения строится из того же канонического маскота;
- релизная сборка проверяет наличие всех шести ассетов внутри `.app`;
- light/dark screenshots регенерируются из реального runtime-компонента;
- README и дизайн-документация синхронизированы с фактической сборкой.

## Проверка выпуска

CI для релиза выполняет unit tests, русскоязычный контракт, Universal 2 build, codesign, 16 snapshot PNG, проверку resource bundle, ZIP integrity и SHA-256.

Если Developer ID/notarization credentials не настроены в GitHub Secrets, GitHub Release автоматически остаётся prerelease с ad-hoc signature. Это не влияет на содержимое и проверку mascot assets.
