# Remote AI v0.2.2 — мультисессии, канонический маскот и DMG

Выпуск расширяет рабочий сценарий Remote AI и переводит macOS-дистрибутив на нормальный установочный DMG.

## Что изменилось

- добавлена поддержка нескольких рабочих сессий через `WorkspaceCollection`;
- одна сессия может включать несколько локальных папок проекта;
- Mutagen синхронизирует несколько папок, а Claude Code получает дополнительные каталоги через `--add-dir`;
- добавлено переключение сессий из интерфейса и меню строки состояния;
- плавающее окно маскота можно перемещать мышью;
- восстановлены и закреплены канонические PNG-ассеты пиксельного облака для всех 6 состояний;
- удалены временные, дублирующие и устаревшие варианты маскота и старый AppIcon SVG;
- генерация AppIcon и status-bar presentation используют канонические ресурсы;
- значок строки меню переведён на нативный template icon с цветным индикатором состояния;
- расширены unit/release snapshot tests для новых моделей и ассетов;
- CI теперь обязательно собирает и проверяет `.dmg`;
- release pipeline публикует `RemoteAI-<version>-macOS.dmg` как основной дистрибутив и сохраняет ZIP как резервный артефакт;
- при настроенных Apple credentials DMG подписывается Developer ID, отдельно проходит notarization и получает staple ticket.

## Установка

Скачайте `RemoteAI-0.2.2-macOS.dmg`, откройте образ и перетащите `RemoteAI.app` в `Applications`.

Если Developer ID/notarization secrets не настроены в GitHub Actions, выпуск автоматически помечается как prerelease. В этом случае macOS Gatekeeper может запросить дополнительное подтверждение запуска.

## Совместимость

Сборка остаётся Universal 2 (`arm64 + x86_64`). Минимальная версия системы по `Package.swift` и `Info.plist` — macOS 13.0.
