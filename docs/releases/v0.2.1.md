# Remote AI v0.2.1 — русский интерфейс и оформленный репозиторий

Выпуск переводит Remote AI на единый русскоязычный продуктовый контракт.

## Что изменилось

- полностью русифицированы Настройки, контекстное меню маскота, tooltips и accessibility;
- переведены уведомления, validation errors, SSH/Mutagen diagnostics и runtime statuses;
- сырой англоязычный вывод tmux/Mutagen больше не используется как основной статус приложения;
- fallback-анализ состояния Claude понимает релевантные русские и английские markers;
- локальный Git-обзор в Warp получил русские заголовки и подсказки;
- `CFBundleDevelopmentRegion` переключён на `ru`;
- light/dark release snapshots содержат русские подписи;
- README и проектная документация полностью переоформлены на русском;
- добавлены русский CONTRIBUTING, SECURITY, localization contract и GitHub issue/PR templates;
- agent prompts закрепляют русский язык как обязательный acceptance criterion;
- CI/CD presentation русифицирован, а release notes теперь берутся из подготовленного русского файла вместо автогенерации GitHub;
- сохранены Universal 2, codesign, snapshots, ZIP/SHA-256 и остальные release gates v0.2.0.

## Совместимость

Технические identifiers, CLI commands, API/library names и машинные state tokens не переводятся намеренно. Это сохраняет совместимость с OpenSSH, Mutagen, tmux, Claude Code, Warp и существующими runtime protocols.

## Подпись

Если Apple Developer ID/notarization credentials не настроены в GitHub Actions, выпуск публикуется как prerelease с ad-hoc codesign. После добавления credentials тот же pipeline поддерживает Developer ID signing, notarization, staple и Gatekeeper verification.
