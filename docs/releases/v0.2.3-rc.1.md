# Remote AI v0.2.3-rc.1 — предварительная сборка DMG

**Статус: предварительный выпуск для тестирования. Не подписан Apple Developer ID и не прошёл notarization Apple.** На некоторых Mac Gatekeeper может блокировать запуск. До массового распространения требуется официальный сертификат Apple Developer ID и публикация подписанного стабильного `v0.2.3`.

## Исправления

- Восстановлена проверенная на macOS CI сборка Universal 2 установщика DMG.
- Установщик содержит `RemoteAI.app` и ярлык `Applications`; оформление Finder фиксируется без запуска Finder (headless dmgbuild).
- Для установщика и резервного ZIP публикуются SHA-256 и проверяемые артефакты.
- GitHub Packages теперь получает идентичный DMG как OCI-артефакт `ghcr.io/f2re/remote_ai:v0.2.3-rc.1`. Пакет не является контейнером для запуска приложения.
- Исправлены защиты релиза: опубликованные файлы не перезаписываются, стабильный выпуск без Apple notarization блокируется, а неподписанный вариант разрешён только при явном суффиксе `-rc.N`.

## Установка

Скачайте `RemoteAI-0.2.3-rc.1-macOS.dmg` со страницы релиза, откройте образ и перенесите `RemoteAI.app` в папку `Applications`. Для тестирования выбирайте установку в отдельной среде.

## Требования

macOS 13.0 или новее согласно manifest; Apple Silicon или Intel (Universal 2). Для работы с удалённым Claude Code необходимы SSH, tmux и Mutagen согласно `README.md`.
