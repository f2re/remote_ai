# Remote AI v0.2.3 — подготовка доверенного DMG и безопасность релизов

Выпуск укрепляет CI/CD и документацию установки на macOS. Основной дистрибутив — Universal 2 DMG, резервный — ZIP.

## Изменения

- публичный GitHub Release теперь не создаётся без Developer ID Application signing и успешной notarization приложения и DMG;
- при частичной конфигурации Apple credentials сборка завершается ошибкой с понятным сообщением;
- сертификат импортируется во временный keychain, секреты доступны только требующим их шагам, временные файлы удаляются после выполнения job;
- дополнительно проверяются `codesign`, `stapler validate`, Gatekeeper и целостность DMG;
- добавлен безопасный интерактивный скрипт `tools/configure-apple-signing.sh` для загрузки Apple credentials в GitHub Secrets;
- обновлены документация, история изменений и инструкция установки DMG; минимальная версия в README согласована с `Info.plist` и `Package.swift`;
- сохранены резервный ZIP, детерминированные снимки интерфейса и `SHA256SUMS.txt`.

## Установка

Скачайте `RemoteAI-0.2.3-macOS.dmg`, откройте образ и перетащите `RemoteAI.app` в папку `Applications`.

Публичный выпуск v0.2.3 разрешён **только после** успешной проверки сертификата Apple Developer ID и notarization (app + DMG). До выполнения этих требований доступны только непубликуемые CI-кандидаты.

## Совместимость

Universal 2 (Apple Silicon `arm64` и Intel `x86_64`). Минимальная версия по manifest и Info.plist — macOS 13.0.

Для настройки SSH-сервера и Mutagen см. `README.md`. Для деталей подписи и release pipeline — `docs/RELEASE.md`.
